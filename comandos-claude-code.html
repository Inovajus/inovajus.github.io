Os comandos / do Claude Code

No Claude Code, digitar / no começo da mensagem abre um menu de comandos prontos: limpar a conversa, trocar o modelo, revisar o trabalho e muito mais. Aqui estão 122 comandos nativos, explicados em português e organizados do mais útil para o mais especializado. Cada um diz também o que acontece na aba Code do Claude Desktop.

    Se for decorar só cinco

    O roteiro mínimo para começar. A última linha de cada cartão diz como fazer o mesmo na aba Code do Desktop.

    1. No primeiro uso do projeto/initCria o CLAUDE.md com as instruções do projeto.No DesktopPeça: “Crie um CLAUDE.md com instruções para esta pasta”.
    2. Antes de uma mudança grande/planO Claude propõe um plano antes de mexer em qualquer arquivo.No DesktopEscolha Plan no seletor de modo, embaixo da caixa de pedido.
    3. Quando a conversa crescer/context · /compactVeja o que ocupa a memória da conversa e resuma para liberar espaço.No DesktopOs dois funcionam na caixa de pedido. O anel de contexto também mostra o quanto já foi usado.
    4. Quando algo der errado/rewindVolta a conversa e os arquivos a um ponto anterior.No DesktopNão confirmado pela documentação. Trabalhe numa cópia da pasta ou com o Git.
    5. Ao trocar de assunto/clearComeça uma conversa nova, sem misturar contextos.No DesktopClique em + New session, na barra lateral.

    Onde digitarNo começo da mensagem. O que vem depois do comando vira argumento.
    <arg> e [arg]Entre < > é obrigatório; entre [ ] é opcional.
    Skill e WorkflowSkill é uma habilidade embutida. Workflow distribui o trabalho entre vários ajudantes em segundo plano.
    Clique para copiarClique no nome do comando para copiá-lo. Nem todo comando aparece para todo mundo: na dúvida, rode /help.
    FuncionaA documentação do Desktop confirma que o comando funciona na aba Code.
    Outro caminhoNo Desktop, o mesmo resultado sai por um botão, um menu ou um pedido. O comando digitado não foi confirmado.
    Não funcionaA documentação diz que não está disponível na aba Code.
    Não confirmadoA documentação do Desktop não diz. Teste digitando / na caixa de pedido.
