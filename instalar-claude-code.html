Instale o Claude Code no seu computador

Um passo a passo para quem nunca abriu um terminal. São quatro passos, cerca de quinze minutos, e você não precisa saber programar.

  • 15 min do início ao fim
  • Windows e Mac
  • Sem programar
  • Sem ser administrador

Primeira vez? Comece pela aba Antes de começar, logo abaixo.

Windows PowerShell 
# 1. cole o comando e aperte Enter
PS C:\Users\voce> irm https://claude.ai/install.ps1 | iex
# 2. espere o cursor voltar (não aparece barra de progresso)
# 3. abra uma janela nova e confira
PS C:\Users\voce> claude --version
2.1.211 (Claude Code)
# pronto! agora é só digitar: claude

O que é o Claude Code, em uma frase

É o Claude trabalhando dentro de uma pasta do seu computador. Em vez de só conversar, ele lê os arquivos daquela pasta, cria arquivos novos e faz tarefas por você.

Pense num assistente sentado na sua mesa: você pede em português, ele mostra o que pretende fazer e só age quando você autoriza.

Ele roda numa janela de texto chamada terminal. Ela parece coisa de programador, mas aqui você vai usá-la só para colar três ou quatro comandos.

O que você precisa ter

Um computador

Windows 10 (versão 1809) ou mais novo, ou Mac com macOS 13 ou mais novo, e pelo menos 4 GB de memória.

Internet

O programa é baixado na instalação e conversa com o Claude pela internet o tempo todo.

Um plano pago do Claude

Pro, Max, Team ou Enterprise, ou uma conta do Console com créditos. O plano gratuito não dá acesso.

Quinze minutos

Sem pressa. Você não precisa ser administrador do computador nem instalar outro programa antes.

Cinco palavras que vão aparecer

Terminal
Uma janela onde você dá ordens por escrito. No Windows ela se chama PowerShell; no Mac, Terminal.
Comando
Uma linha de texto que o computador executa quando você aperta Enter. Aqui você só vai copiar e colar.
Colar no terminal
No Windows, Ctrl + V ou um clique com o botão direito. No Mac, ⌘ + V.
Pasta de trabalho
A pasta em que você abre o Claude Code. É o único lugar onde ele lê e cria arquivos.
Prompt
O pedido que você escreve para o Claude, em português comum, como numa conversa.

Qual é o seu computador?

Instalação no Windows

Quatro passos. Marque Fiz este passo ao terminar cada um, e a trilha acende. Se algo der diferente do desenho, vá à aba Deu erro?.

1Abra o PowerShell

  1. Aperte a tecla ⊞ Windows (ou clique na lupa da barra de tarefas).
  2. Escreva PowerShell.
  3. Clique em Windows PowerShell ou aperte Enter.
O que você deve ver: uma janela escura com uma linha que começa com PS C:\Users\ e o seu nome.
Não precisa clicar em “Executar como administrador”. Abra do jeito normal.

2Cole o comando de instalação

Clique em Copiar, volte ao PowerShell, cole com Ctrl + V (ou botão direito do mouse) e aperte Enter.

irm https://claude.ai/install.ps1 | iex
Por que é seguro: o comando baixa o instalador oficial direto do site da Anthropic, a empresa que faz o Claude.
A janela que abriu é o Prompt de Comando (CMD)?

Se a linha começa só com C:\, sem o PS na frente, você está no CMD. Use este comando no lugar do de cima:

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

3Espere terminar

O instalador não mostra barra de progresso. Parece que nada está acontecendo, mas ele está baixando. Pode levar de um a alguns minutos, conforme a internet.

Terminou quando: aparecem mensagens dizendo que a instalação foi concluída e a linha PS C:\Users\...> volta a piscar, esperando um novo comando.
Não feche a janela nem aperte nada enquanto espera.

4Abra uma janela nova e confira

Feche o PowerShell e abra outro, como no passo 1. A janela antiga não “enxerga” o programa recém-instalado. Na janela nova, cole:

claude --version
Deu certo se aparecer um número seguido de (Claude Code), por exemplo 2.1.211 (Claude Code). O número muda com as atualizações.
Apareceu “não é reconhecido”? Veja o primeiro item da aba Deu erro?.

Instalação no Mac

Quatro passos. Marque Fiz este passo ao terminar cada um, e a trilha acende. Se algo der diferente do desenho, vá à aba Deu erro?.

1Abra o Terminal

  1. Aperte ⌘ Command + Espaço. Abre a busca do Mac (Spotlight).
  2. Escreva Terminal.
  3. Aperte Enter.
O que você deve ver: uma janela com uma linha terminada em % e um cursor esperando.

2Cole o comando de instalação

Clique em Copiar, volte ao Terminal, cole com ⌘ + V e aperte Enter.

curl -fsSL https://claude.ai/install.sh | bash
Por que é seguro: o comando baixa o instalador oficial direto do site da Anthropic, a empresa que faz o Claude.
Já usa o Homebrew? Há outro caminho

Quem já tem o Homebrew pode instalar com brew install --cask claude-code. Atenção: por esse caminho o programa não se atualiza sozinho; de tempos em tempos rode brew upgrade claude-code. Se você não sabe o que é Homebrew, ignore e use o comando de cima.

3Espere terminar

O instalador não mostra barra de progresso. Parece parado, mas está baixando. Pode levar de um a alguns minutos.

Terminou quando: aparecem mensagens dizendo que a instalação foi concluída e a linha com % volta, esperando um novo comando.
Viu um aviso sobre o PATH no fim da instalação? Anote. Se o passo 4 falhar, a aba Deu erro? resolve com um comando.

4Abra uma janela nova e confira

Aperte ⌘ + N para abrir uma janela nova do Terminal. A janela antiga não “enxerga” o programa recém-instalado. Na nova, cole:

claude --version
Deu certo se aparecer um número seguido de (Claude Code), por exemplo 2.1.211 (Claude Code). O número muda com as atualizações.
Apareceu “command not found”? Veja o primeiro item da aba Deu erro?.

Instalado no Mac!

Agora vamos abrir o Claude Code pela primeira vez e fazer o login.

Primeiro uso: login e o primeiro pedido

Vale para Windows e Mac. Use o mesmo terminal da instalação (PowerShell ou Terminal). As telas do Claude Code aparecem em inglês; abaixo está o que cada uma quer dizer.

1Crie uma pasta só para ele

O Claude Code trabalha dentro da pasta em que você está. Para treinar, crie uma pasta nova e vazia e entre nela. Cole um comando de cada vez, com Enter depois de cada um:

mkdir meu-primeiro-projeto
cd meu-primeiro-projeto
Em português: mkdir cria a pasta; cd entra nela. O nome da pasta passa a aparecer na linha do terminal.

2Abra o Claude Code e faça o login

claude

Na primeira vez, ele faz algumas perguntas. Use as setas ↑ ↓ para escolher e Enter para confirmar:

  1. Estilo do texto (cores claras ou escuras): escolha o que for mais confortável de ler.
  2. Forma de login: escolha a conta do Claude com assinatura. O navegador abre sozinho.
  3. No navegador, entre na sua conta do Claude e clique em Autorizar. Depois volte para o terminal.
  4. “Você confia nos arquivos desta pasta?”: como a pasta é sua e está vazia, confirme que sim.
O navegador não abriu? O terminal mostra um endereço começando com https://. Copie, cole no navegador e, se aparecer um código, cole-o de volta no terminal.

3Faça o primeiro pedido

Escreva em português, como numa conversa, e aperte Enter. Por exemplo:

Crie um arquivo chamado ideias.txt com cinco nomes divertidos para um gato.

Antes de criar o arquivo, ele pede sua permissão. Leia o que ele vai fazer e escolha Yes (sim). Depois abra a pasta meu-primeiro-projeto no seu computador: o arquivo estará lá.

Regra de ouro: leia sempre o pedido de permissão antes de aceitar. Se não entender, escolha No e pergunte a ele o que aquilo faz.

Deu erro? Calma, quase sempre é simples

Copie um pedaço da mensagem que apareceu no seu terminal e cole na busca. Os erros abaixo são os mais comuns na instalação.

O comando claude não funciona depois de instalar

O termo 'claude' não é reconhecido como nome de cmdlet… / command not found: claude

Por quê: a janela foi aberta antes da instalação, ou o computador ainda não sabe em que pasta o programa ficou.

Resolva: primeiro, feche o terminal e abra outro. Se continuar, cole o comando do seu sistema, aperte Enter e abra uma janela nova de novo.

Windows (PowerShell):

[Environment]::SetEnvironmentVariable('PATH', [Environment]::GetEnvironmentVariable('PATH','User') + ";$env:USERPROFILE\.local\bin", 'User')

Mac (Terminal):

echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

“irm” não é reconhecido

'irm' não é reconhecido como um comando interno ou externo, um programa operável ou um arquivo em lotes.

Por quê: a janela aberta é o Prompt de Comando (CMD), não o PowerShell.

Resolva: feche e abra o PowerShell (passo 1 do Windows). Ou use o comando alternativo para CMD, que está no passo 2.

Erro com “&&” no PowerShell

O token '&&' não é um separador de instrução válido nesta versão.

Por quê: você colou no PowerShell o comando feito para o CMD.

Resolva: use o comando principal do passo 2: irm https://claude.ai/install.ps1 | iex.

Comando do Mac usado no Windows

'bash' não é reconhecido… / Não é possível localizar um parâmetro que coincida com o nome de parâmetro 'fsSL'

Por quê: o comando com curl … | bash é só para Mac.

Resolva: no Windows, use o comando do passo 2 da aba Windows.

“A execução de scripts foi desabilitada”

… não pode ser carregado porque a execução de scripts foi desabilitada neste sistema.

Por quê: isso acontece quando o Claude Code foi instalado por outro caminho (o npm). O instalador desta página não é afetado.

Resolva: instale pelo comando do passo 2. Se precisar manter o npm, este comando libera scripts só para o seu usuário. Em computador de empresa, pergunte antes à equipe de TI.

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

O login não funciona ou a conta não tem acesso

O navegador não abriu / a conta não tem acesso ao Claude Code

Por quê: o navegador pode não abrir sozinho, ou a conta usada é do plano gratuito, que não inclui o Claude Code.

Resolva: copie o endereço https:// que aparece no terminal e cole no navegador. Confira se a conta tem plano Pro ou superior. Para trocar de conta, digite /login dentro do Claude Code.

Erro estranho logo ao instalar

syntax error near unexpected token '<' / erro 403

Por quê: em vez do instalador, a internet devolveu uma página web. Costuma acontecer em redes de empresa com bloqueio, ou em países onde o Claude não é oferecido.

Resolva: tente em outra rede (a de casa, por exemplo). No computador do trabalho, peça ajuda à equipe de TI.

Nada acima resolveu

Qualquer outro problema

Resolva: rode o diagnóstico abaixo, que aponta o que está errado e sugere a correção. Se ainda assim travar, consulte a página oficial de solução de problemas, em inglês: code.claude.com/docs/en/troubleshoot-install.

claude doctor

Nenhum erro com esse texto. Tente uma palavra só, como reconhecido ou login, ou rode claude doctor.

Perguntas frequentes

As dúvidas que mais aparecem de quem está começando.

Preciso saber programar?

Não. Você escreve em português o que quer, como numa conversa. O terminal só entra para instalar e para abrir o programa.

É de graça?

Não. O Claude Code exige um plano pago do Claude (Pro, Max, Team ou Enterprise) ou uma conta do Console da Anthropic com créditos. O plano gratuito do site não dá acesso. Os preços estão em claude.ai.

Preciso ser administrador do computador?

Não. O instalador coloca o programa dentro da sua pasta de usuário. Em computadores de empresa ou órgão público, porém, a equipe de TI pode bloquear instalações; nesse caso, peça autorização antes.

Preciso instalar Node.js, Python ou Git antes?

Não. O instalador desta página já traz tudo. No Windows, o Git é opcional: sem ele, o Claude Code usa o próprio PowerShell.

Qual a diferença para o Claude do site ou do aplicativo?

O Claude do site conversa e devolve texto. O Claude Code também conversa, mas age: lê e cria arquivos na pasta em que foi aberto e executa tarefas no computador, sempre pedindo sua permissão antes.

É seguro deixar o Claude mexer nos meus arquivos?

Ele pede autorização antes de criar ou mudar arquivos e antes de rodar comandos. Três cuidados bastam no começo:

1. Abra sempre dentro de uma pasta própria, nunca na pasta pessoal inteira. 2. Leia cada pedido de permissão antes de aceitar. 3. Não use documentos confidenciais nem dados pessoais de outras pessoas sem autorização de quem responde por eles.

Ele se atualiza sozinho?

Sim, na instalação desta página: a atualização acontece em segundo plano e vale na próxima vez que você abrir. Para atualizar na hora, use claude update. Quem instalou pelo Homebrew ou WinGet precisa atualizar manualmente.

Fechei a janela sem querer. Perdi tudo?

Não. Os arquivos criados continuam na pasta. Para continuar a conversa, abra o terminal na mesma pasta, digite claude e depois /resume para escolher a conversa anterior.

Posso usar em mais de um computador?

Sim. Instale em cada um e faça login com a mesma conta.

Funciona no Linux? E no celular?

No Linux, sim: use o mesmo comando do Mac. No celular não há instalação, mas a versão web em claude.ai/code funciona pelo navegador. O Windows de 32 bits não é suportado.

Como desinstalar?

No Windows, cole no PowerShell, um de cada vez:

Remove-Item -Path "$env:USERPROFILE\.local\bin\claude.exe" -Force
Remove-Item -Path "$env:USERPROFILE\.local\share\claude" -Recurse -Force

No Mac, cole no Terminal:

rm -f ~/.local/bin/claude && rm -rf ~/.local/share/claude

Seus arquivos de trabalho não são apagados. As configurações e o histórico ficam na pasta .claude da sua pasta de usuário; apague-a só se quiser zerar tudo.
