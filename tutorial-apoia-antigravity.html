Leia primeiro: o veredito de conformidade

Este tutorial funciona. A pergunta relevante não é se dá para conectar — dá —, e sim se você pode conectar processos reais. Nos planos individuais do Antigravity, a resposta hoje é não.

Incompatibilidade nos planos individuais

Os Termos Adicionais do Google Antigravity declaram que o Google registra e armazena os dados do usuário, os dados de interação, os metadados e o feedback — o conjunto que os termos chamam de Interactions. E declaram que essas Interações são usadas para avaliar, desenvolver e melhorar pesquisa, produtos, serviços e tecnologias de aprendizado de máquina do Google e da Alphabet, podendo ser acessadas e revisadas por funcionários e contratados.

A exclusão não é automática: os termos indicam pedido por e-mail para antigravity-support@google.com, e informam que, até o pedido, as Interações seguem sendo usadas na forma do contrato.

Isso colide de frente com a exigência que o próprio ApoIA imprime na tela antes do botão de gerar a URL — usar o MCP em IA que aproveita os dados para treinamento viola a LGPD e a Resolução CNJ nº 615/2025, e só devem ser usadas IAs com política de zero retenção.

A exceção que torna o uso viável

O cabeçalho dos mesmos termos abre uma porta: quem acessa o serviço por Gemini Enterprise (Google Cloud), Gemini Enterprise for Business ou assinatura Google Workspace sob os Pre-GA Offering Terms fica submetido aos termos aceitos pelo administrador da organização — e os Termos Adicionais deixam de se aplicar.

Ou seja: a via de conformidade não é um botão dentro do aplicativo, é um contrato assinado pelo órgão. Enquanto a Justiça Federal não tiver esse acesso institucional configurado e o instrumento contratual verificado pelo encarregado de dados, a regra prática é simples.

  • Conta Google pessoal (Free, Pro, Ultra): use a integração apenas com dados fictícios ou números de processo de teste. Nunca com autos reais.
  • Acesso institucional com termos assinados: uso liberado, observadas as demais cautelas desta página.
  • Em dúvida sobre qual é o seu caso: trate como pessoal. O ônus de provar a conformidade é de quem conecta.
Sobre a chave de preferência nas configurações

Os termos mencionam que o usuário pode alterar, nas configurações, a preferência sobre esse uso dos dados. Vale acionar — mas uma chave em conta pessoal não é o mesmo que garantia contratual de não retenção. A Resolução CNJ nº 615/2025 e o aviso do ApoIA pedem garantia, não configuração. Não use a chave como fundamento para conectar autos reais.

Duas camadas adicionais a verificar

Produto em preview. O Antigravity segue em fase de pré-lançamento. Políticas de retenção, cotas e controles administrativos podem mudar sem aviso longo — o que já é, por si, um fator de risco para dado processual.

Modelo de terceiro. Os termos preveem que, ao escolher um modelo de terceiro ou de código aberto como modelo principal do agente, você passa a se sujeitar também aos termos daquele fornecedor. Se o agente roda em modelo não-Google, a análise de conformidade precisa cobrir os dois contratos.

Como a ligação funciona

O Model Context Protocol (MCP) é um protocolo aberto que permite a clientes de IA acessarem ferramentas e fontes de dados externas. O ApoIA — IA generativa integrada à PDPJ-Br, desenvolvida pelo TRF2 — publica um Servidor MCP próprio, exposto como servidor remoto HTTP por uma URL pessoal que já carrega o token de autenticação.

O Antigravity, do Google, é um ambiente de desenvolvimento agêntico com suporte nativo a MCP. Conectado o servidor, o agente passa a consultar metadados e teor de peças, além das ferramentas de jurisprudência e biblioteca do ApoIA, sem sair do editor. O alcance continua limitado aos processos que a sua credencial PDPJ já enxerga.

O que muda em relação ao Claude

Quem já configurou o ApoIA no Claude vai reconhecer o passo 1 e estranhar o resto. As diferenças não são cosméticas — duas delas mudam o risco da operação.

AspectoClaudeAntigravity
Cadastro Formulário gráfico em Personalizar › Conectores Edição manual de arquivo JSON
Campo da URL Campo “URL do servidor MCP remoto” serverUrl — obrigatório. url e httpUrl não são aceitos
Onde fica o token Guardado pela plataforma Texto puro em arquivo no seu disco
Ativação Chave liga-desliga por conversa Global ou por workspace, sempre ativo enquanto não desabilitado

A mudança de risco que importa

No Claude, a URL com o seu token fica sob a guarda da plataforma. No Antigravity, ela fica em um arquivo de texto legível no seu perfil de usuário — sujeito a backup automático, sincronização de pastas, varredura de antivírus corporativo e, se você usar a configuração por workspace, a commit acidental em repositório. Quem tiver esse arquivo consulta processos em seu nome, com o seu perfil.

Antes de começar

  • Conformidade resolvida — a leitura do veredito não é opcional. Defina agora se este ambiente vai ver dados reais ou apenas fictícios.
  • Acesso ao ApoIA em apoia.pdpj.jus.br, com login pelo PDPJ ou credenciais do CNJ.
  • Antigravity instalado e autenticado, em versão recente. A documentação consultada descreve o Antigravity 2.0, o Antigravity IDE, a Antigravity CLI e o SDK — os caminhos de menu variam entre eles.
  • Saber qual produto você abriu. “Antigravity 2.0” e “Antigravity IDE” são superfícies distintas, com telas distintas. Confira o nome na tela inicial antes de seguir o passo 2.
  • Um editor de texto à mão, já que a configuração é feita em arquivo.
  1. 1

    Passo 1Gerar a URL no ApoIA

    1. Abra https://apoia.pdpj.jus.br e autentique-se pelo PDPJ ou com as credenciais do CNJ.
    2. Na tela inicial, localize o cartão MCP — ícone de tomada, com a descrição “Model Context Protocol”. O item também aparece no menu da barra superior.
    3. Abra a página MCP e desça até o bloco Configurar, que instrui a cadastrar a URL no cliente MCP como servidor remoto (HTTP).
    4. Clique em Gerar URL. O link criado contém o seu token de acesso individual.
    5. Copie o link e mantenha-o na área de transferência.
    A contagem do prazo começa no login

    A validade é de até 8 horas contadas do momento do login no ApoIA — não do momento em que a URL é gerada. Se você já estava logado desde cedo, saia e entre de novo antes de gerar, para aproveitar o prazo integral.

    Confira a lista na própria tela

    Abaixo do bloco Configurar, o ApoIA lista as ferramentas publicadas para o seu perfil. Essa lista é a real e prevalece sobre a tabela desta página.

  2. 2

    Passo 2Abrir o mcp_config.json

    O ApoIA não está na loja de MCP do Antigravity — é servidor customizado, e a rota é a edição do arquivo de configuração. O caminho até ele depende do produto.

    No Antigravity IDE

    1. Clique em … no topo do painel lateral do agente e escolha MCP Servers.
    2. Clique em Manage MCP Servers.
    3. Clique em View raw config. O arquivo abre no editor.

    No Antigravity 2.0

    1. Clique em Settings, no canto inferior esquerdo da tela.
    2. Selecione Customizations e localize a seção Installed MCP Servers.
    3. É nessa seção que os servidores são instalados, desativados, atualizados e removidos. Para o servidor customizado, edite o arquivo diretamente.

    Onde o arquivo fica

    EscopoCaminhoQuando usar
    Global ~/.gemini/config/mcp_config.json Padrão. Vale para todos os projetos.
    Workspace .agents/mcp_config.json Dentro do projeto. Ver o Anexo B antes de adotar.
    Divergência de caminho entre versões

    A documentação oficial atual aponta o caminho global ~/.gemini/config/mcp_config.json. Guias de terceiros e versões anteriores do IDE citam ~/.gemini/antigravity/mcp_config.json. Os dois aparecem na prática, conforme a versão instalada.

    Regra segura: use o botão View raw config e edite o arquivo que a própria ferramenta abriu. Não crie o arquivo “no caminho certo” às cegas — você corre o risco de editar um arquivo que a sua versão não lê.

    No Windows com WSL, atenção ao lado do disco

    Se o Antigravity roda no Windows, ~ é C:\Users\SEU_USUARIO. Se roda dentro do WSL, é o home da distribuição Linux. São arquivos diferentes. Editar o do lado errado produz exatamente o sintoma de “configurei e não apareceu nada”.

  3. 3

    Passo 3Escrever a configuração

    O arquivo tem um único objeto mcpServers, com uma chave por servidor. Se o arquivo estiver vazio, cole isto inteiro:

    {
  "mcpServers": {
    "apoia": {
      "serverUrl": "COLE_AQUI_A_URL_GERADA_NO_APOIA"
    }
  }
}

    Se já houver outros servidores, acrescente "apoia" como chave irmã, cuidando da vírgula entre os blocos:

    {
  "mcpServers": {
    "github": {
      "serverUrl": "https://exemplo/mcp/"
    },
    "apoia": {
      "serverUrl": "COLE_AQUI_A_URL_GERADA_NO_APOIA"
    }
  }
}
    O erro que mais derruba a conexão

    O campo é serverUrl. A documentação é explícita: para conexões remotas por Streamable HTTP, SSE ou websocket, os campos legados url e httpUrl não são suportados. Quem copia configuração de tutorial de Cursor ou Claude Desktop tropeça exatamente aqui — e o servidor simplesmente não aparece, sem mensagem de erro clara.

    Não preencha headers

    A autenticação do ApoIA já vai embutida no token da URL. O objeto headers existe para servidores que exigem cabeçalho Authorization próprio — não é o caso. Deixe de fora. O mesmo vale para oauth e authProviderType.

    Dois campos opcionais que valem a pena

    {
  "mcpServers": {
    "apoia": {
      "serverUrl": "COLE_AQUI_A_URL_GERADA_NO_APOIA",
      "disabled": false,
      "disabledTools": ["calculator"]
    }
  }
}
    • "disabled": true — desliga o servidor sem apagar a configuração. Útil para manter o bloco pronto e ligar só quando for usar.
    • "disabledTools" — lista de ferramentas que o modelo não enxerga. Quanto menor a superfície exposta, menor o risco e menor o custo de contexto.
    Salve e valide o JSON

    JSON não perdoa vírgula sobrando nem aspas curvas. Se o editor não acusar erro de sintaxe, o arquivo provavelmente está bem formado — mas um arquivo inválido faz todos os servidores sumirem, não só o novo.

  4. 4

    Passo 4Recarregar e conferir

    1. Salve o arquivo.
    2. No IDE, volte ao painel MCP Servers e use o botão de atualizar. Se nada mudar, feche e reabra o Antigravity — o recarregamento em quente nem sempre pega.
    3. No Antigravity 2.0, use o botão de refresh na seção Installed MCP Servers.
    4. Confirme que apoia aparece na lista com as ferramentas expandidas. Servidor listado mas sem ferramentas significa que a conexão falhou — vá a Problemas comuns.
    O que esperar

    Uma conexão saudável expõe, no mínimo, processMetadata e piecesText. O conjunto completo varia com a versão do ApoIA e o seu perfil de acesso — ausência de alguma ferramenta da tabela não indica erro de configuração.

  5. 5

    Passo 5Testar a integração

    Faça o primeiro teste com um processo cujo conteúdo você já conheça, para conferir se o retorno bate. Em ambiente de conta pessoal, use número fictício ou de teste.

    Use o servidor MCP "apoia" para obter os metadados do processo
0000000-00.0000.0.00.0000 e listar as peças disponíveis.
Em seguida, traga o teor da petição inicial.

    Na primeira execução, o agente pede aprovação para chamar a ferramenta — é o modo Ask, que é o padrão. Autorize e observe: um teste bem-sucedido devolve os dados do processo e a relação de peças, e o pedido seguinte aciona piecesText.

    Confira sempre o retorno

    A integração dá ao agente acesso ao conteúdo dos autos, mas não substitui a conferência humana. Verifique número, partes, datas e valores antes de usar qualquer resumo em minuta ou decisão, como exige a Resolução CNJ nº 615/2025.

Ferramentas disponíveis

A documentação oficial destaca duas ferramentas principais. Na prática, a conexão expõe um conjunto mais amplo, que varia conforme a versão do ApoIA e o perfil do usuário.

FerramentaO que faz
processMetadataPrincipal. Metadados e informações gerais do processo a partir do número, com anonimização e proteção de dados sensíveis. É ela que devolve os identificadores das peças.
piecesTextPrincipal. Teor das peças e documentos, a partir do número do processo e dos identificadores das peças.
semanticSearchBusca semântica ou híbrida de temas de repercussão geral do STF e de repetitivos do STJ.
leadingCaseSearchLocaliza temas de repercussão geral e repetitivos pelo número do processo paradigma.
precedentBusca de precedentes por consulta textual com operadores lógicos (e, ou, não, aspas, truncamento).
pangeaBusca teses, súmulas, orientações jurisprudenciais e temas no Pangea.
libraryDocumentRecupera documentos da biblioteca pessoal do usuário no ApoIA.
currentDate, addDate, dateDiff, calculatorUtilitários para contagem de prazos, idade na DER, tempo de tramitação e cálculos simples.
A ordem de chamada não é opcional

processMetadata vem sempre antes de piecesText: é a primeira que devolve os identificadores exigidos pela segunda. Em processo volumoso, peça ao agente para listar o índice de peças e propor um recorte antes de puxar o teor. Carregar dezenas de peças de uma vez estoura a janela de contexto e degrada a análise — não é um efeito neutro.

Renovação do token

A URL expira em até 8 horas contadas do login no ApoIA. Vencido o prazo, as chamadas passam a falhar com erro de autenticação, ou o servidor aparece como desconectado. Para restabelecer:

  1. Faça novo login no ApoIA.
  2. Volte ao menu MCP e clique em Gerar URL.
  3. Abra o mcp_config.json, substitua o valor de serverUrl pela URL nova e salve.
  4. Atualize os servidores no painel MCP, ou reinicie o Antigravity.
Este é o ponto de atrito diário

No Claude, a troca é um campo de formulário. Aqui, é editar arquivo todo dia. Para quem usa a integração diariamente, o hábito que funciona é gerar a URL no início do expediente, junto com o login nos demais sistemas, e deixar o mcp_config.json aberto em uma aba fixa do editor. Se a renovação virar fricção, o uso morre em duas semanas — vale automatizar ou aceitar que este ambiente é para sessões pontuais, não para rotina.

Permissões e superfície exposta

O acesso às ferramentas MCP é governado pelo sistema de permissões do Antigravity. Por padrão, ferramentas não configuradas rodam em modo Ask — cada chamada pede aprovação. A política aceita três formas de liberação:

PadrãoAlcanceRecomendação
mcp(apoia/processMetadata)Uma ferramenta específicaPreferível. Libere só o que você usa.
mcp(apoia/*)Todas as ferramentas do ApoIAAceitável em ambiente controlado.
mcp(*)Todas as ferramentas de todos os servidoresEvite. Curinga global em máquina com dado processual é risco desnecessário.
Injeção de prompt vinda dos autos

O conteúdo de uma peça processual é texto de terceiro, e pode conter instruções dirigidas ao modelo. Num agente de IDE — que edita arquivos, roda comandos e navega — isso é mais perigoso do que numa interface de conversa. Manter o modo Ask nas ferramentas de escrita e execução é a principal defesa disponível. Comportamento fora do pedido é incidente, não curiosidade: interrompa e registre.

  • Desative o que não usa. Se a sessão é só de pesquisa de jurisprudência, ligue o ApoIA e desligue os demais servidores.
  • Não misture repositórios. Evite abrir projetos de terceiros com o ApoIA ativo.
  • Encerre a sessão e apague a URL do arquivo em equipamento compartilhado.

Problemas comuns

SintomaCausa provávelO que fazer
O servidor não aparece na lista Uso de url ou httpUrl em vez de serverUrl Trocar o nome do campo e recarregar
Todos os servidores sumiram de uma vez JSON inválido — vírgula sobrando, chave sem fechar, aspas curvas Validar a sintaxe do arquivo inteiro

Anexo A — Antigravity CLI

A CLI usa o mesmo formato de configuração e aceita servidores remotos com o mesmo campo serverUrl.

  1. Digite /mcp no painel de prompt e pressione Enter para abrir o MCP Manager Overlay.
  2. O painel mostra o status de cada servidor — ativo, desconectado ou carregando —, permite recarregar as configurações e inspecionar os registros de conexão em tempo real.
  3. Para editar manualmente, o arquivo global é ~/.gemini/config/mcp_config.json; o de workspace, .agents/mcp_config.json.
Histórico do shell

Se você usar qualquer comando que receba a URL como argumento, ela fica registrada no histórico do terminal. Em máquina compartilhada, prefira sempre a edição do arquivo.

Anexo B — Configuração por workspace

O Antigravity permite configurar servidores dentro do projeto, em .agents/mcp_config.json. É conveniente para isolar o ApoIA em uma pasta de trabalho judicial específica, sem deixá-lo ativo em todo projeto que você abrir.

Risco alto: credencial dentro do repositório

Esse arquivo fica na árvore do projeto. Se a pasta estiver sob controle de versão, a sua credencial de acesso a processos entra no repositório no primeiro commit — e, se o remoto for compartilhado, vaza para todos que tenham acesso.

Antes de adotar o escopo de workspace, acrescente ao .gitignore:

.agents/mcp_config.json

E confirme com git status que o arquivo não aparece como rastreado. Se já foi commitado alguma vez, considere o token comprometido: gere uma URL nova e trate o histórico do repositório. Na dúvida, fique no escopo global.

Tutoriais desta série

O mesmo Servidor MCP do ApoIA se conecta a três clientes diferentes. Cada um tem procedimento próprio e implicações distintas de conformidade:

  • Conectar o ApoIA ao Claude — cadastro por formulário, com o token guardado pela plataforma.
  • Conectar o ApoIA ao ChatGPT — formulário gráfico, mas exige ligar o Modo de desenvolvedor.
